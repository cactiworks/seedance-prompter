# Интерфейс

## Источники

- **Figma-файл Lab UI v2.1** (CC BY 4.0) — значения токенов и геометрия компонентов. Выгружен в
  `design/lab-ui/`.
- **Сайт lab.pics — эталон качества**: как система ведёт себя в собранном продукте (решение 8). Перед
  любой работой над интерфейсом — прочитать `design/lab-ui/REFERENCE.md` (измерения, принципы, таблица
  переноса, список запрещённого) и посмотреть `design/lab-ui/reference-site/home-*.png`. Новый экран
  сверяется с эталоном бок о бок скриншотом, а не по памяти.
- Раскладка и поведение оболочки — от connxn.ui (сайдбар, вкладки, лента + composer + параметры,
  библиотека, canvas); карточка работы, правка, библиотека с папками — по образцу Higgsfield
  (решения 25, 26). Кожа — всегда Lab UI.

## Правила

- В CSS приложения только `var(--lab-*)`: сырые цвета, радиусы и тени запрещены stylelint.
  `src/web/ui/tokens/tokens.css` генерируется `scripts/design/build-tokens.ts`, руками не правится.
- Шрифты — Geist и Geist Mono (подтверждено Figma-файлом, 20.09).
- Тема по умолчанию светлая; тёмная и «авто» — переключателем, выбор в localStorage (решение 20).
- Liquid glass — только на плавающем хроме; формы и превью промпта — solid.
- Интерфейс по-русски. В форме «Кадров» поля только русские (правило — [patterns.md](patterns.md),
  п. 7), английский виден в превью и строкой «в промпте: …» под полем. В студии, canvas и правке
  промпт можно писать напрямую, на любом языке.
- Всё платное — кнопка с ценой; отправка картинок провайдеру или в LLM — после согласия.
- Подтверждение опасного действия — на месте кнопки, а не диалогом: диалог встал бы под просмотр
  (решение 36).
- Компоненты UI-kit живут в галерее `/ui` во всех вариантах и состояниях; новый компонент — сначала там.
- Атрибуция Lab UI (lab.pics, lemone, Meowdes, «ported to React/CSS») обязательна: `README.md` и
  `design/lab-ui/ATTRIBUTION.md`.


## Навигация и onboarding (11.10.2026)

- Стартовый и неизвестный hash открывают Canvas. Главные вкладки: Canvas / Производство / Изображения / Видео / Материалы.
  Меню «Инструменты»: Seedance-сценарий (`#/shots`), Помощник промптов (`#/prompter`), Калибровка.
- «Как пользоваться» в шапке открывает CreatorGuide: темы по задачам, переходы на реальные экраны и
  подсветка `data-guide` anchors. Подсказку можно закрыть Esc; запусков моделей при выборе темы нет.
- На пустом Canvas — создание холста и четыре шаблона. Внутри холста «Добавить» группирует материалы,
  генерацию и обработку. Список работ в sidebar, подключения свёрнуты до запроса пользователя.
- «Сохранить схему» — JSON, «Скачать» у результата — медиафайл. «Открыть и править» в блоке открывает
  общий MediaPreview; для изображения — правку, для видео — доступный апскейл. Обрезка видео — блок Canvas.
- Подборки генераций, ролики Seedance и холсты пока отдельные сущности. Названия не должны обещать
  единый клиентский проект или автоматическую сборку финального видео.

## Production: Codex-подготовка и mock-медиа (12.10.2026)

`#/production` — вертикальная лента десяти раскрываемых этапов с превью, статусами и счётчиками.
Вверху переходы к фото, видео до Topaz и выдаче; в sidebar — серии. Два milestone принимают
выбранные версии, QC-брак недоступен для приёмки. Inspector показывает файл, prompt, версию,
исходник и mock task ID; правка сохраняет прежний кадр. Сбой и retry видны внутри своего этапа.
Данные, pause и approvals переживают reload. Новая серия по умолчанию предлагает реальную
подготовку Codex, явно указывая расход квоты и 2–4 вызова. «Только mock» сохраняет прежний
бесплатный проход. Первый этап показывает две роли, паспорт, допущения/ограничения, 1–8 кадров
и раскрываемые read-only prompts. При ошибке показан явный retry незавершённой роли, уже готовая
сцена остаётся видна. Счётчики кадров динамические; до плана общее количество обозначено «—».
Медиа, QC и upscale обозначены mock; плейсхолдеры не выдаются за иллюстрацию реального плана.
Медиа-списаний нет, Codex usage показан отдельно. Фото/MP4 скачиваются для ручного монтажа.

Общий Dialog: body имеет `flex: 0 1 auto`, header/footer не сжимаются. `flex: 1` при fit-content
в WebKit схлопывал тело и обрезал кнопки. Прокрутка остаётся внутри body; проверены onboarding,
photo edit и inspector в Yab (размер снимка 1024 × 640; CSS viewport/zoom не измерены).
В Chromium дополнительно проверен точный viewport 1024 × 640.

Владелец обычно открывает платформу почти на весь экран. Проверены 1440/1280 px и обе стороны
затронутых breakpoints: 1089/1087 и 769/767 px, дополнительно 1024 px; высота 1000 px.


## Персонаж Production (14.10.2026)

Блок «Персонаж · Soul ID» есть в новой и сохранённой серии. Dialog использует общий UI-kit:
список со статусами и отдельная форма создания с локальными превью, удалением из набора,
согласиями и кнопкой в фиксированном footer. Body прокручивается, footer не сжимается.
Выбрать можно completed v2; failed/unknown и неподтверждённая версия не маскируются под готовность.
Сходство лица не обещается: выбранный персонаж сохраняется, а mock-файлы остаются прежними.


Исправления alpha-аудита (14.10.2026): на ширине <=768 px sidebar по умолчанию свёрнут и открывается
поверх workspace; Studio переносит параметры в modal при узкой контентной области. Library toolbar
и selection bar переносятся строками. Canvas размещает блоки с учётом занятых мест, Fit измеряет
высоту DOM; порты работают через Tab/Enter/Space, Escape возвращает focus, связи удаляются в отдельном
диалоге. Удаление холста требует повторного клика и предлагает восстановление. Общий Dialog возвращает
focus на opener. Production не закрывает читаемый этап при обновлении статуса; manual toggle имеет
приоритет. В справке есть маршрут «Серия контента по сценарию» с явной границей mock-медиа.
