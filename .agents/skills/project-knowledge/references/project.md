# Проект

## Что это

Локальная система AI-креатора одного владельца на его Mac (только `127.0.0.1`). Выросла из
конструктора промптов Seedance 2.5 по гайду школы Cinema Ai Tech (решения 1–20) и с 27.09.2026 стала
системой, которая сама генерирует картинки и видео через API (решение 21).

Владелец думает по-русски и заполняет поля тезисами; английский текст промптов пишут агенты
(решение 18). Детерминированное ядро — компилятор, линтер, нумерация референсов — работает без LLM.

## Части продукта

- **Seedance-сценарий** (раньше «Кадры», меню «Инструменты») — конструктор промпта Seedance 2.5: ролик из кадров с общим миром и памятью между
  кадрами, референсы с нумерацией по панели, режимы съёмки и монтаж, агенты (поля, планировщик,
  писатель, критик), окно проверки, попытки с разбором и фиксером, экспорт в Higgsfield вручную или
  генерация через KIE.
- **Изображения / Видео** — студия: лента сессии, composer с картинками и ролями, параметры модели, цена
  на кнопке. Каркас взят у connxn.ui (решение 25).
- **Помощник промптов** (меню «Инструменты») — идея по-русски с референсами → промпт под конкретную модель с объяснением выбора;
  «В генератор» переносит результат в форму, сам ничего не генерирует (решения 28–29).
- **Canvas** — основной вход, холсты с блоками: генераторы, кадр из видео, обрезка, размер, апскейл Topaz,
  Seedance-промптер нодой (решения 35–37, 39).
- **Производство** (`#/production`) — сценарий и вектор → две роли Codex: смысловые события, паспорта локаций, 1–8 кадров
  и prompts. В photos после отдельного cost gate: профиль внешности → master → обязательный критик →
  независимые фото Soul 2 → отбор → ручная приёмка. Legacy сохраняет I2I с общим master. Видео и upscale
  отключены. Demo сохраняет оба mock milestone и правку версий; модели в нём не вызываются.
  Codex расходует квоту по клику, выбранный Soul ID сохраняет привязку внешности.
- **Материалы** (раньше «Библиотека») — всё сгенерированное и свои файлы, папки, просмотр «Результат / Правка» (для видео — «Апскейл») по образцу
  Higgsfield, рецепты починки, правка кистью, инструменты (решения 26, 30, 32, 34, 36).
- **Калибровка** — наборы тестовых прогонов, журнал оценок, правило с третьего повтора → карточка
  модели (решение 33).

## Рамки, заданные владельцем

- Один пользователь, локально, с нуля. С 14.10.2026 владелец явно разрешил публичный remote
  `github.com/cactiworks/seedance-prompter`, заменив прежнее решение 38 о приватности кода.
  Разрешение не распространяется на личные данные, фото, ключи и новые чужие материалы.
- LLM — Codex / OpenAI через локальный `codex exec` с входом в ChatGPT, только по клику владельца.
  KIE и Higgsfield отвечают только за генерацию и обработку медиа (решение 12.10.2026).
- Платные генерации и набор моделей — решения владельца, подробно в [generation.md](generation.md).
- Не нужны: критик промптера, попытки в промптере, герои как сущности между промптами (28.09).
- Новые модели и разделы (аудио ElevenLabs / Suno и т. п.) — только решением владельца.

## Модуль производства

Владелец задаёт сценарий и визуальный вектор; модуль должен выдавать согласованные фото и клипы
для ручного монтажа. Codex по сценарию/вектору готовит единый паспорт, 1–8 кадров и prompts;
детали определяет режиссёр, промежуточная сцена сохраняется. Ошибка или рестарт не повторяют LLM
автоматически. Медиа-каркас сохраняет остановки после фото и перед upscale, частичную приёмку,
историю, паузу/retry и mock-правку с сохранением исходника. Управление Soul ID и выбор для серии
подключены; применение identity к изображениям, Seedream, настоящий QC/upscale
и интеграция с медиатекой ещё впереди. Подготовленный план не меняет demo-медиа. План — в
[docs/PRODUCTION-PLAN.md](../../../../docs/PRODUCTION-PLAN.md), статус — в `docs/BACKLOG.md` →
«Промышленный контент». Для этой работы консилиум не подключается.
