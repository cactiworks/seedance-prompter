# Знания проекта

Текущие факты о системе — здесь. Почему так решили — `docs/DECISIONS.md` (журнал, только
дописывается). Что дальше и статус этапов — `docs/BACKLOG.md`. Исходный план v1 от 20.09.2026 —
`docs/archive/PLAN-2026-09-20.md`: история, не источник текущего состояния. Детали реализации — код.

## Какой файл читать

| задача | файл |
|---|---|
| что это за продукт, для кого, что в рамках и что нет | [project.md](references/project.md) |
| где живёт часть системы, слои, данные на диске, API, агенты, LLM-мост | [architecture.md](references/architecture.md) |
| правка ядра, компилятора, линтера, агентов; инварианты; проверки и секреты | [patterns.md](references/patterns.md) |
| KIE, Higgsfield, цены, гейт стоимости, замер, задачи и библиотека | [generation.md](references/generation.md) |
| любой экран и компонент интерфейса | [ux-guidelines.md](references/ux-guidelines.md) |
| запуск, второй экземпляр, `doctor`, что нужно на машине | [deployment.md](references/deployment.md) |

Правка, которая задевает несколько областей, читает все затронутые файлы.

## Как держать в актуальном виде

У факта один файл-владелец — тот, чья тема в таблице выше. В других файлах факт может упоминаться ради
связности. Меняешь факт — правь владельца и найди упоминания:
`rg -n '<ключевое слово>' .agents/skills/project-knowledge`. Когда переносить следствия решений
сюда — `AGENTS.md` → «Конец сессии».
