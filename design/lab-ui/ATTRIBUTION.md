## Что изменено

Система существует только как Figma-файл. В этом проекте она перенесена в код: переменные и стили
файла преобразованы в CSS custom properties (`src/web/ui/tokens/`), компоненты воссозданы на React +
CSS Modules (`src/web/ui/components/`), использовано подмножество иконок в виде SVG. Компоненты,
которых в Lab UI нет (метры бюджетов, карточка референса с номером, блоки промпта с подсветкой,
diff), собраны из её токенов и примитивов и помечены в галерее `/ui` как производные.

## Состав системы (по описанию авторов)

Primitive и semantic токены · true liquid glass, ambient-материалы, solid-вариации · прогрессивные тени
и блюры, background blur · адаптивы desktop и mobile · доступные светлая и тёмная темы с повышенной
контрастностью · масштабирование 75–133 % · 30+ компонентов · флаги всех стран · 400+ outline и filled
иконок · инструкции, гайдлайны по цвету и типографике.

`community-cover.png` — обложка файла со страницы Figma Community, сохранена как визуальный ориентир.
