# Эталон качества: сайт lab.pics

Владелец, 20.09.2026: сайт студии — живое воплощение Lab UI, на него опираться как на референс
качественного дизайна наравне с Figma-файлом. Снято с https://lab.pics (Framer, светлая тема, 1440×900):
скриншоты `reference-site/home-*.png`, измерения `reference-site/computed-styles.json`.

**Иерархия источников.** Значения токенов и геометрию компонентов даёт Figma-файл (после M0-d).
Сайт даёт то, чего в файле нет: как система *ведёт себя в собранном продукте* — плотность, воздух,
ритм, иерархия, сдержанность. До получения файла измерения ниже — рабочие значения токенов.

## Что измерено на живом сайте

### Цвет (сайт отдаёт палитру Lab UI CSS-переменными, цвета в display-p3)
| роль | значение |
|---|---|
| акцент | `#007aff`; производные по непрозрачности: 72 % `b8` · 52 % `85` · 32 % `52` · 20 % `33` · 12 % `1f` · 8 % `14` · 4 % `0a` · 2 % `05` |
| статусы | красный `#ff362e` · оранжевый `#ffa300` · зелёный `#1acf57` · синий-2 `#3d87ff` — с той же лестницей непрозрачности |
| текст | основной `#0f0f12` · вторичный `#3d3d42` на 72 % · третичный на 52 % · отключённый на 32 % |
| заливки контролов | `#787880` на 20 / 16 / 12 / 8 % (нейтральные подложки, hover, разделители) |
| поверхности | `#ffffff` и `#f7f7fa`; стеклянные — белый на 92 / 85 / 80 / 64 / 48 / 32 / 20 % |
| тёмные | `#0f0f12`, `#101012` — основная тёмная кнопка и тёмные карточки |

Лестница непрозрачности одна на все цвета — это и есть «цвет × непрозрачность» из v2.1.1.

### Типографика
- Сайт набран **Geist Variable** + **Geist Mono** (в демо-коде самой системы указан `Inter Variable`;
  семейство для приложения фиксируется по текстовым стилям Figma-файла; до тех пор — Geist: он стоит
  на эталоне и распространяется под OFL).
- Размеры: 12 · 14 · 16 (основной, 69 % текста) · 20 · 24 · 32 · 48 · 112. Веса — только **400 и 500**.
- Интерлиньяж: 18@12 · 14–20@14 · 24@16 · 20@20 (подзаголовки набраны плотно, 1.0) · 32@32 · 48@48.
- Трекинг отрицательный и растёт с кеглем: −0.01em @12–16 · −0.02em @20 · −0.03em @32 · −0.04em @48.

### Форма, тень, блюр
- Радиусы: 4 · **8** (самый частый — мелкие контролы, ячейки) · 12 · 16 · 24 · 32 · pill `999px`.
- Границы — 1px нейтральной заливкой (8–12 %), не серым цветом.
- Прогрессивная тень — стек из 5 слоёв с растущим blur и падающей непрозрачностью:
  `0 7px 16px rgb(109 114 131 / 3%), 0 28px 28px … 3%, 0 63px 38px … 2%, 0 113px 45px … 0, 0 176px 49px … 0`.
  Малая: `0 1px 2px rgb(0 0 0 / 6%), 0 2px 4px rgb(0 0 0 / 8%)`. Кромка: `inset 0 -1px 1px rgb(16 16 18 / 12%)`.
- Background blur: 12px (малые стеклянные элементы) · 48px (панели) · 128px (ambient-пятна).

## Принципы, которые видны в собранном продукте

1. **Тишина.** Белый и `#f7f7fa`, один акцентный цвет, статусные цвета только там, где есть статус.
   Ни градиентов-украшений, ни цветных фонов секций. Акцент — на действии и выделенном состоянии.
2. **Иерархия весом и непрозрачностью, а не размером и цветом.** Два веса; вторичное — тот же цвет на
   72 / 52 %. Неактивные пункты списка (Custom-fit / Code-friendly / …) — просто третичный текст.
3. **Много воздуха снаружи, плотно внутри.** Поля страницы 72px, между блоками 120–200px; внутри
   карточки дашборда — 12px-подписи, строки таблицы 40px, зазоры 8–16px. Плотность живёт в данных.
4. **Подпись над значением.** Мелкая вторичная подпись (12px) сверху, значение крупнее снизу — в
   статистике, карточках документов, строках ролей. Мой паттерн для метров и параметров.
5. **Контролы — пилюли и мягкие прямоугольники.** Кнопка-действие — pill; segmented control — pill с
   белым бегунком и малой тенью на нейтральной подложке; поля и ячейки — радиус 8; карточки — 16–24.
6. **Граница тоньше, чем кажется нужным.** Карточка отделена 1px на 8 % и едва заметной тенью —
   никаких рамок «для надёжности».
7. **Иконки контурные, синие, 28–32px как якорь блока**; в плотном UI — 16px нейтральные.
8. **Штриховка — язык пустоты.** Плейсхолдер контента — диагональная штриховка в скруглённой рамке.
   Мой паттерн для пустого референса, пустого сегмента, незаполненного слота.
9. **Стекло только там, где есть что размывать:** парящая панель над контентом (меню, плеер, хедер при
   прокрутке). На ровном белом стекла нет.
10. **Основное тёмное действие.** Рядом с синим primary существует почти чёрная pill-кнопка
    (`Show filters`) — вторичное весомое действие без второго акцентного цвета.
11. **Движение — мягкое появление и сдвиг, без отскоков.** Секции входят прозрачностью + 8–16px.

## Как это переносится на Seedance Prompter

| на сайте | у меня |
|---|---|
| дашборд: шапка с поиском и тёмной pill-кнопкой, статистика «подпись над значением» | шапка кадра; липкая строка метров: события · фон · речь · длина |
| таблица с тегами статусов и 40px-строками | список сегментов и битов, панель линтера (severity-теги тех же статусных цветов) |
| segmented control File / Edit / View | переключатели «плейсхолдеры / итог», диалект, вкладки правой панели |
| меню с `⌘T`-подсказками | меню действий блока, пикер плейсхолдеров |
| штриховка-плейсхолдер | пустой слот референса, сегмент без текста |
| курсоры-ярлыки с именами (Daniel, Max) | цветные ярлыки 7 категорий подсветки промпта — те же статусные цвета на 12 % фоне |
| карточки документов на телефоне: подпись, имя, тег статуса | карточка референса: номер, роль, флаги |
| список слева с одним активным пунктом | навигация проекта: активный — основной текст, остальные — третичный |

**Запрещено** (чего на эталоне нет): цветные фоны секций, больше одного акцента, жирные веса 600+,
тени «для объёма» на плоских элементах, рамки толще 1px, стекло на ровном фоне, эмодзи вместо иконок.
