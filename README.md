# Seedance Prompter

Локальный конструктор промптов для Seedance 2.5. Заполняешь параметры кадра по-русски — получаешь
английский промпт по правилам гайда Cinema Ai Tech, с автоматической нумерацией референсов, проверкой
линтером и журналом попыток.

> Репозиторий не публиковать: внутри текст чужого гайда и вызовы LLM по личной подписке Claude Code.

## Запуск

Двойной клик по `Запустить.command` — откроется вкладка `http://127.0.0.1:4317`.
То же из терминала: `npm start`. Остановить — `Ctrl+C` в окне терминала или просто закрыть его.

Первый раз после скачивания: `npm install`.

## Где что лежит

- `data/` — твои проекты, референсы, попытки. Обычные файлы, в git не попадают. Бэкап — скопировать папку.
- `docs/PLAN.md` — архитектура и этапы. `docs/DECISIONS.md` — решения, статус, чек-лист ручных действий.
- `packs/cinema-doc/` — правила гайда как данные. `docs/source/` — снимок самого гайда.
- `design/lab-ui/` — всё, что вытянуто из Figma-файла дизайн-системы.

## Если LLM не отвечает

Инструмент зовёт твой же `claude` (подписка). Проверь `claude auth status`; если разлогинило —
`claude` → `/login`. При исчерпанном лимите всё, кроме кнопки «Написать кадр», продолжает работать.
