# UX research и черновик onboarding

11.10.2026. Первый сегмент — AI-креаторы, которые делают рекламу и контент для клиентов. Deployment пока не выбран владельцем.

Уточнение 12.10.2026: продуктовые LLM-агенты переведены на Codex / OpenAI; текст согласия в
`onboarding` актуализирован. Аудит и его ссылки фиксируют состояние 11.10.2026; историческое
упоминание `CLAUDE.md` сохранено, текущие правила доступны в корневом `AGENTS.md`.

**Текущая версия:** запусти приложение и открой Canvas → «Как пользоваться».

**Исследование:** [research.html](research.html) — выводы, структура платформы, сценарии, потребности разных стилей, приоритеты и план проверки с креаторами. Затем открой [интерактивный Canvas](prototype/index.html) и нажми «Пройти onboarding».

Документы также доступны в Markdown: [исследование](research.md), [onboarding](onboarding.md), [конкуренты](competitors.md), [аудит текущего продукта](current-product-audit.md). Все выводы о текущей реализации привязаны к исходникам; внешние факты — к primary URLs.

Прототип полностью статический: API/LLM не вызываются, изображения иллюстративные, настоящий MP4 не создаётся. Изменения демо живут только до перезагрузки вкладки. JSON-download содержит план демо и явно отличается от media export. Это описание исходного статического черновика. По последующей обратной связи владельца UX-изменения внедрены в `src/`: текущий вход — Canvas, справка «Как пользоваться» работает прямо в приложении. Прототип сохранён как материал исследования.

## Открытие

`prototype/index.html` можно открыть напрямую. Для общего reader и всех переходов удобно запустить из этой папки:

```sh
python3 -m http.server 4322 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:4322/`. Готовые HTML не зависят от внешней сети. `render.mjs` пересобирает HTML из Markdown, используя локальный bundled `marked`; он не нужен для просмотра.

## Проверка

- Текущий интерфейс изучен на отдельном экземпляре с тестовыми данными. Платных генераций не было.
- Полный `npm run check` прошёл: TypeScript, ESLint, Stylelint, 27 test files / 294 tests, Vite build. Build сообщает обычное предупреждение о chunk больше 500 kB; оно не относится к статическому черновику.
- Проверены 90 локальных ссылок в документах/reader: отсутствующих targets нет. Генерация HTML и syntax check JavaScript выполнены.
- В браузере пройдены основной demo flow и семь шагов tour, Back/Next, закрытие и повторный запуск. Проверены сохранение источника версии и возврат focus после Help.
- Responsive evidence и metadata находятся в `prototype/`: точные размеры 1440×900, 1024×768, 390×844. Отдельный visual review ограничен подготовленными screenshots и исходниками; это не полный accessibility audit.
- `evidence/current-canvas.png` и `evidence/prototype-canvas.png` — preview снимков Yab при viewport 1280×800, уменьшенные до 1024×640.

Эти проверки подтверждают работоспособность черновика и документов. Удобство для креаторов, качество generation и охват всех потребностей требуют pilot по плану в research.
