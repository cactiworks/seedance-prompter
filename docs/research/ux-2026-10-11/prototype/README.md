# Canvas-first · интерактивный UX-черновик

Открой `index.html` в браузере. Нужен только статический HTTP-сервер или открытие файла; backend не используется.

Все иллюстрации условные, выполнены SVG внутри demo. Запросов к API, LLM и provider нет; секреты не читаются. Изменения хранятся только в памяти вкладки и сбрасываются после reload. Полный production workflow этим прототипом не реализован.

## Что проверять

- Главный рабочий путь: бриф клиента → продуктовый reference → варианты → локальная правка → движение → обрезка и передача.
- Выбор A/B/C обновляет inspector и происхождение следующей ветки. Правка создаёт новую demo-версию; исходный вариант остаётся в истории.
- Seedance встроен в контекст выбранного кадра: «Просто» и «По сцене» показывают разную глубину настройки.
- Onboarding из семи шагов: запуск сверху или из «Помощи», spotlight по реальным элементам, действия внутри walkthrough, назад/дальше, закрытие, Escape и управление фокусом.
- Обрезка ограничивает интервал от 0 до 5 секунд, не короче 0.5 секунды. Выгружается **только JSON-план**, не MP4; media export явно недоступен.
- «Материалы» возвращают материал на тот же Canvas; «Экспорты», «Подключения», «Задачи» и «Проекты» объясняют место в системе.
- Desktop 1440, compact desktop 1024 (Canvas прокручивается), mobile — линейный путь и inspector ниже.

Оценка `$0.40 / 5 сек` — условные demo-числа для проверки гейта стоимости, не действующий тариф.

Кожа следует локальному Lab UI reference: Geist 400/500, светлая поверхность, мягкие нейтральные границы, один синий акцент. Lab UI — lab.pics, lemone, Meowdes, CC BY 4.0; adapted/ported to standalone HTML/CSS. Geist распространяется под OFL; лицензия в `fonts/LICENSE`.

## Проверка черновика

`qa-results.json` — результаты локального Chromium-прохода, `qa.mjs` — воспроизводимый script с путями bundled runtime на этом Mac. Скрипт ожидает статический сервер на `http://127.0.0.1:4329/`.

PNG evidence сняты без масштабирования viewport: `responsive-1440.png` — 1440×900; `responsive-1024.png` — 1024×768; `responsive-390.png` — 390×844. `tour-1024.png` — шаг 5 при 1024×768, `tour-390.png` — шаг 2 при 390×844; снимки после завершения перехода spotlight.

Проверены выбор и происхождение варианта, новая demo-правка, возврат фокуса при запуске тура из «Помощи», семь шагов и завершение тура, границы обрезки, JSON download, все sidebar views. Ошибок JavaScript в проходе нет. На 1024 Canvas прокручивается внутри своей области; горизонтального переполнения страницы нет. Это проверка прототипа, не production приложения.
