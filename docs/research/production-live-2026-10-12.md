# Production: реальный фото-pilot, 12.10.2026

Техническая цепочка прошла. Серия целиком не прошла визуальный QC: между независимыми кадрами
меняются комната и предметы. Identity владельца не проверена — в API-аккаунте нет Soul ID.
Seedance и Topaz не запускались.

Прямое разрешение владельца: «сам пройди все проверки с платными генерациями (до сиданса)».
Это ограниченный pilot через существующую студию. В самом Production медиа/QC остаются mock;
его первый milestone не принят, реальные фото не подменяют демонстрационные артефакты.

## QC по результатам

- **Кадр 1, окно:** свет и настроение подходят. Появился второй блокнот; мелкий загнутый уголок
  не читается. Лицо не является лицом владельца — Soul ID не задан.
- **Кадр 2, запись:** крупность полезная, но вместо маленького уголка получился большой заворот
  поперёк левой страницы. Стол/окно/кресло отличаются от первого кадра. Нужна правка и continuity-check.
- **Кадр 3, деталь:** модель показала перелистывание целой страницы, а не маленький уголок.
  Появились дополнительные предметы/ручки. Для заявленного действия кадр не принят.
- **Правка кадра 2:** Seedream убрал заворот и восстановил плоскую страницу. При визуальном сравнении
  положение руки, ручки, окна, стола и одежды сохранилось. Pixel-perfect неизменность не заявляется:
  результат имеет другое разрешение. Исходный PNG и его hash сохранены.
- **Vision:** заметил дефект страницы. При этом looksGenerated=false для известной генерации:
  этот флаг нельзя использовать как доказательство реалистичности или прохождения QC.

Вывод для следующей реализации: текстовый паспорт полезен для планирования, но не фиксирует геометрию
сцены. Нужны принятый master image сцены, отдельная identity, генерация следующих ракурсов с reference
и сравнение результата с обоими источниками. Это рекомендация по одному pilot, а не измеренная
гарантия качества или массовый benchmark. Один seed при изменении prompt не заменяет reference сцены.

## Расход

| Генерация | Подтверждённое списание | Источник |
|---|---:|---|
| Soul 2, 3 фото | 3 × $0.005625 = $0.016875 | Amount charged в трёх деталях Requests Higgsfield |
| Seedream 5 Pro, 1 правка | 14 кр = $0.07 | creditsConsumed=14; KIE balance 1074 → 1060 |
| Всего медиа | **$0.086875, примерно $0.087** | Оценка перед запуском была $0.088 |

Higgsfield status API не отдаёт сумму; в локальных jobs creditsConsumed=null. Фактическое списание
сверено отдельно в кабинете, не записано задним числом в provider response. Codex использовал
ChatGPT-подписку: 4 успешных вызова, 49 279 input и 2 183 output tokens; долларовая цена не определялась.

## Актуальные API-факты

- [Soul 2 Text to Image](https://open.higgsfield.ai/models/higgsfield-ai/soul/v2/standard/api-reference):
  текущий контракт сверён, estimate 1080p дал $0.006. Запуск выполнен на Soul 2, не на Soul Cinema.
- [Soul 2 Image to Image](https://open.higgsfield.ai/models/higgsfield-ai/soul/v2/image-to-image/api-reference):
  документирован отдельный image_url для сцены и custom_reference_id для identity; маршрут пока не
  интегрирован в локальный каталог и в этом pilot не запускался.
- Soul ID можно перечислить: GET /v1/custom-references/list?page=1&page_size=20.
  Живой ответ текущего аккаунта — items: []. Прежний вывод об отсутствии endpoint устарел.
- [Seedream 5 Pro KIE](https://kie.ai/seedream-5-pro): image-to-image, high/2K, один вход;
  фактический запрос прошёл через существующий адаптер и cost/consent gate.
- [Обновление Codex CLI](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex):
  официальный npm-путь обновления; установлен и проверен 0.162.1.
