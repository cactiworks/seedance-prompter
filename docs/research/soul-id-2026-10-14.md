# Soul ID в Production — проверка 14.10.2026

Реализован отдельный flow: локальные фото → подтверждение передачи и неизвестной цены →
создание Soul ID v2 → статус → выбор для серии. Генерация кадров, QC и upscale остаются mock.

## Проверено

- `npm run check`: 353 теста в 32 файлах, TypeScript, ESLint, Stylelint и Vite build прошли.
- Adapter: POST custom-references с model_version v2; presigned upload с выданными headers,
  без API-ключа на storage; один запрос создания без сетевых повторов.
- Backend: отсутствие consent/подтверждения цены, битые/отсутствующие/повторяющиеся фото,
  дубли requestId, queued → in_progress → completed, потеря ответа, восстановление после
  рестарта, импорт страниц, неподтверждённая/v1 версия, смена статуса перед выбором.
- Серия: выбранный completed v2 сохраняется после reload, входит в manifest; смена/отвязка
  защищена rev и не изменяет mock-артефакты. Оба milestone пройдены на локальных fixtures.
- Клиент: запоздалый список не стирает только что созданного персонажа; ошибка выбора видна
  внутри Dialog. Неудачное/неопределённое создание нельзя выбрать как готовое.
- Browser: локальная загрузка восьми тестовых рисунков, оба подтверждения, создание через
  подменённый provider, статусы, reload, выбор, отвязка, светлая/тёмная тема. Нет JS errors
  и запрещённых внешних запросов. Нижние кнопки внутри viewport, длинная форма прокручивается.
- Размеры: 1440×1000, 1280×900, 1089×900, 1087×900, 1024×640, 769×900, 767×900.
  Дополнительный smoke окна создания в Yab/WebKit; снимок 1024×640 без измерения CSS viewport.
- Независимый layout-review, wave 1: clean. Проверены новая и сохранённая серия,
  Dialog, длинные имена, статусы и ошибки на всех семи размерах; обрезки кнопок нет.

Browser evidence и изолированный QA server:
`/tmp/seedance-soul-id-qa-L9g2c9/` (вне git). Там provider подменён и внешний fetch запрещён;
счётчик create=1 относится к fake provider. Реальные фото не отправлялись, платных запусков нет.

## Ограничения

Реальное обучение, списание, доступность API аккаунту и сходство лица не проверялись.
Цена обучения не опубликована; UI и backend требуют явного подтверждения неизвестной цены.
Общий Soul ID OpenAPI не содержит model_version; используется model-specific инструкция Soul 2.
Импорт без версии сохраняется как unknown и недоступен для выбора. Обработчик удаления Soul ID
не добавлялся. Исходные локальные фото остаются в data/uploads, состояние — в data/characters.
