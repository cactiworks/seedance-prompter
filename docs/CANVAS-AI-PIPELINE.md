# Canvas AI pipeline

Согласованная задача от 17.11.2026: управляемый путь одного шота с двумя отдельными AI-стадиями и ручной проверкой. Первый набор моделей — Soul 2 и Seedance 2.5. Качество идеи, prompt и медиа оценивает пользователь.

## Одна ветка

`comments → AI фото → одобренная русская идея → отдельная сборка prompt → одобрение prompt → Soul 2 → приёмка фото → AI видео → одобренная русская идея движения → отдельная сборка prompt → одобрение prompt → Seedance`.

Модель, параметры и Soul ID принадлежат целевому генератору. AI хранит явную ссылку на него. Comments можно переиспользовать между ветками; порядок входов виден. AI видит напрямую подключённые изображения и явно показанные локальные фото выбранного Soul ID. Персонаж необязателен. Soul ID без локальных фото не позволяет собрать prompt с внешностью до добавления фото.

Принятый снимок подключается одновременно к AI видео и `start` Seedance. Character sheet может быть контекстом AI; в режиме стартового кадра он отдельно в Seedance не отправляется. Для первого внедрения комментарии текстовые. Правки идеи и prompt идут через чат, английский prompt доступен для чтения и копирования.

## Пять B-roll

Пять шотов — пять независимых веток, у каждой собственные AI фото/видео, prompts и генераторы. Один общий comment задаёт концепцию, локальные comments — сюжет фото и движение видео. Шаблоны `managed-broll` и `managed-five-broll` создают только граф без LLM/генерации. Prompt-ноды появляются после отдельного действия сборки. Параметры шаблонов берутся из текущего каталога; длительность Seedance по умолчанию 5 секунд.

## Контроль

Одобрение относится к конкретной версии и снимку входов. Изменение comments, модели, параметров, Soul ID, refs или выбранного медиа требует пересмотра. Повторное подтверждение применимости оставляет историю и создаёт новую версию/review-запись. Перемещение блоков не меняет актуальность.

Перед вызовом read-only preview показывает конкретные inputs. Start/retry передают digest показанного набора: при смене фото Soul ID или байтов reference даже без изменения Flow сервер возвращает `PREVIEW_CHANGED` до inference. UI получает новый preview, снимает согласие и сохраняет написанный feedback. Повторный AI-вызов автоматически не отправляется. Revalidate создаёт самостоятельную durable запись с новыми снимками и файлами, `calls: []` и ссылкой на прежнюю запись; старые JSON и изображения неизменны.

История AI хранится на сервере отдельно от компактной проекции в Flow. Поздний ответ сохраняется в своей попытке, не перезаписывает другой контекст. После остановки — только явный retry. Изоляция ChatGPT/API-подключений сохраняется. Каждая генерация хранит Canvas lineage: flow, нода, AI, версии идеи/prompt, fingerprint. Сервер проверяет одобренный снимок перед расходом.

Правки готового медиа создаются новой веткой. Для видео AI получает прежнюю идею/prompt и текст замечаний; видео, кадры и звук автоматически не анализируются. Прежний start frame остаётся до явного выбора другого.

## Проверка

Технический gate — `npm run check`, сценарии fake LLM/providers и визуальная проверка. Они не доказывают качество живой генерации. Live-проверку оплачиваемого пути выполняет владелец: одна полная ветка, затем пять разных B-roll. Библиотека референсов и дополнительные модели — следующие расширения.
